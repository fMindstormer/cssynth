## Benchmark solutions downloaded on demand

[Kushalshakya/CSSBattle](https://github.com/Kushalshakya/CSSBattle) publishes
no license, so none of its code or renders are part of this repository.
`bench/cases.json` keeps only each case's title, source path and code length;
`python bench/fetch.py` downloads the solutions at commit
`8972f4aec818e0f5a1657160bb2c8f250be98359` and renders the targets locally.
